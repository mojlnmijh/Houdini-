# 碰撞检测几何，Houdini 刚体交互判定数学
在Houdini刚体仿真里，很多人遇到刚体穿模、弹跳异常、粘滞、爆炸，只会调碰撞厚度和迭代次数，却忽略碰撞检测本质是一套几何判定数学。它分为两个阶段：宽相快速筛选，窄相精确求交，两者配合判断几何体之间是否接触、穿透，并计算接触点、法向与穿透深度，为后续求解器提供约束依据。

宽相是第一层筛选，目标是快速排除不可能碰撞的物体，减少计算开销。常用包围盒、包围球这类简单几何包裹原始模型。求解器先计算每个刚体的包围体，判断包围体之间是否相交。如果包围体没有交集，直接跳过后续精细检测；只有包围体重叠，才进入窄相。这一步是效率的核心，场景里刚体数量越多，宽相的价值越明显。包围盒的更新策略、膨胀系数，直接影响筛选精度，膨胀过大容易误判，过小会漏掉潜在碰撞。

窄相是精确几何求交，也是碰撞判定的核心。针对三角面模型，主流是面与面、点与面的相交测试。数学上，就是判断一个点是否落在三角面片一侧，计算点到面片的最短距离，以及穿透距离。当距离小于碰撞厚度，就判定发生碰撞，同时输出接触法向。法向方向至关重要，它定义了碰撞反弹的推力方向，法向计算出错，刚体就会出现侧翻、莫名弹射。

这里要区分几何表面和碰撞代理。直接用高模三角面做碰撞检测，精度高但速度极慢，因此工程上都会生成简化碰撞代理，比如凸包、复合凸块、胶囊体。凸几何的求交计算更简单稳定，凸包判定的数学逻辑是分离轴定理：只要能找到一条轴，让两个物体在轴上的投影区间不重叠，物体就没有碰撞。分离轴定理是Houdini凸刚体碰撞的底层基础，计算稳定、不容易出现奇异解。凹模型不能直接用单一凸包，必须拆成多个凸块组合，也就是复合凸碰撞体。

穿透深度是碰撞约束的关键数值。一旦检测到穿透，求解器会根据穿透深度，沿着接触法向施加排斥力，把两个物体推开。这个排斥力的大小，和深度、刚度直接相关。刚度越高，同样深度下的修正力越强，收敛更快，但刚度过高容易震荡；刚度偏低，物体会长时间卡在互相穿透的状态，视觉上就是穿模。很多人把碰撞厚度理解为模型的实体厚度，从数学上看，它是碰撞判定的阈值区间，在这个区间内就开始生成接触约束，而不是等到真正穿插之后再修正。

摩擦也是基于碰撞几何信息衍生出来的力学量。接触点生成之后，求解器会根据切平面，计算切向摩擦力。摩擦力限制物体沿着接触面滑动，摩擦系数决定阻碍滑动的强弱。如果接触点分布不均匀、法向杂乱，摩擦就会不稳定，物体出现打滑或者吸住不动的现象。

仿真迭代的过程，就是反复检测、生成约束、修正位置，再重新检测。单次修正之后，物体位置改变，碰撞状态也会变化，多轮迭代用来逐步消除穿透。迭代次数不足，穿透无法完全消除；迭代过多，算力消耗急剧上升。

面向未来的大规模刚体场景，这套几何判定体系还在持续优化。自适应碰撞代理、动态简化、距离场碰撞逐渐普及。距离场把模型内部、外部的距离信息预存进体积网格，检测点直接采样距离值，适合复杂曲面，但是距离场有分辨率上限，细节处容易失真。不同碰撞几何各有取舍：凸包稳定快，距离场适合异形曲面，高精度三角面适合特写资产。

一个常见误区：碰撞代理越精细，效果越好。精细代理会带来大量接触点，计算变慢，还容易产生互相冲突的法向，引发刚体抖动。远景、次要物体，优先用简单凸包；只有特写交互的部件，才使用高精度碰撞形态。

总而言之，Houdini刚体碰撞的底层逻辑，是宽相包围体筛选配合窄相几何求交，依靠分离轴定理、点面距离判定识别接触，输出法向、穿透深度供给求解器做约束修正。理解这套几何判定数学，就能看懂碰撞代理、厚度、刚度、迭代之间的关系，从根源解决穿模、乱弹、粘滞等刚体仿真问题，而不是单纯依靠参数试错。（全文976字）
